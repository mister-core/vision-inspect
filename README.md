# 视觉检查系统(彩色高亮像素计数 + 串口外部报警)

海康 MV-CU013-A0GC(130 万像素彩色 GigE 工业相机)+ OpenCV + PySide6 实现的视觉检查程序:
对 ROI 区域做**三通道窗口像素统计**,超过报警阈值时经**串口**给外部报警设备发送触发帧
`07 00 00 A7`,并锁存报警、保存报警截图。

## 判定算法(与需求方确认的最终版)

对 ROI 内每个像素 (B,G,R):

```
条件1: B_lo ≤ B ≤ B_hi      (蓝色通道窗口)
条件2: G_lo ≤ G ≤ G_hi      (绿色通道窗口)
条件3: R_lo ≤ R ≤ R_hi      (红色通道窗口)
三个条件【同时】成立 → 该像素计入"目标像素"(彩色高亮像素)
ROI 内目标像素总数 N ≥ 报警阈值 → 连续 debounce 帧确认 → 串口发送 07 00 00 A7 → 锁存
```

- 三个通道窗口各自独立(0~255),界面可分别调节,并有快捷预设:
  **白色高亮** R/G/B∈[180,255]、**红色亮斑** R∈[180,255] 且 G/B∈[0,120]、绿/蓝同理。
- 三通道同时命中 = 精准圈定"你要的那种亮色",排除同亮度干扰色
  (例:纯红异物在"白色"窗口下 N=0 不误报,换"红色"窗口即命中 —— 自检第 5/6 项实测通过)。
- 界面实时显示 N、各通道单独达标数、ROI 占比、fps;可开关红色蒙层实时查看命中像素。

## 运行

```bash
# 1) 装依赖（Python 3.10+）
pip install -r requirements.txt

# 2) 生成配置（首次运行）
cp config.example.json config.json      # Windows: copy config.example.json config.json

# 3) 运行
python main.py                 # 启动 GUI
python main.py --selfcheck     # 无界面全链路自检(7项)
```

或直接双击 `启动视觉检查.bat`（需先把 python 加入 PATH）。

> 无需任何硬件即可跑通全流程：信号源默认「模拟器」，自动生成工件底图与异物块。

## 快速体验(无需任何硬件)

1. 启动后信号源默认"模拟器":深色工件背景 + 走线,按需从"模拟缺陷"下拉选
   白色/红色/绿色/蓝色异物块(尺寸由 config 的 sim_defect_w/h 控制),出现位置随机。
2. 点"▶ 启动采集" → 画面出现,绿色"监视中"。
3. 画面上**拖拽**框 ROI(右键=恢复全幅);把"模拟缺陷"切成"白色异物" →
   三帧内 N 超阈值 → 红灯"报警锁存"、日志出现触发帧、snapshots/ 存下报警截图。
4. 撤走缺陷(切回"无缺陷")→ 点"复位报警"恢复监视。
5. 验证窗口威力:预设切"白色高亮"时放"红色异物"→ N=0 不报;换预设"红色亮斑"→ 命中。
6. 阈值调参:红色蒙层开/关直观看到命中像素;实时 N 与单通道计数辅助判断。

## 外部报警设备接线与串口

- 触发帧(十六进制):`07 00 00 A7`,报警发生时发送一次(锁存,不刷屏);
  点"复位报警"解除锁存后才可能再次触发。
- 界面选 COM 口与波特率(默认 9600, 8N1),点"刷新"枚举端口;
  **"启用串口报警"不勾选 = 仅写日志**,方便无报警盒时调试。
- 串口打不开时自动降级为日志并明确提示,检测线不会中断。

## 海康相机联调步骤(真机;本代码真机未联调)

1. 到海康机器人官网 → 机器视觉 → 下载中心,下载安装 **MVS**(含驱动 + MVS Viewer)。
2. 相机供电(9~24V DC 或按 P7 口接法),网线直连电脑网卡(或交换机);
   把相机 IP 与电脑网卡调到**同一网段**(相机默认 192.168.x.x,MVS 里可改)。
3. 打开 **MVS Viewer**,确认能出图、图像清晰(此步成功后才轮到本程序)。
4. 把 `MVS安装目录\Development\Samples\Python\MvImport` **整个文件夹复制到本项目根目录**
   (sources.py 会自动加载;找不到时启动会给出同样指引)。
5. 启动程序,信号源选"海康相机 MVS",启动采集;曝光/增益/帧率滑条直接生效。
   - 相机独占:MVS Viewer 开着会占用相机,本程序连不上时先关 Viewer。
   - 颜色:相机默认输出 BayerGB8,程序按 `BayerGB2BGR` 转换;
     若 MVS Viewer 中像素格式与此不同(如 RGB8),改 `app/sources.py` 中 `_BAYER2BGR` 键或
     `_color_mode` 分支(该文件顶部注释有说明)。
   - 相机只支持自由运行模式时帧率设置自动被忽略,不影响检测。

## 相机参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| 曝光 | 2000 µs | MV-CU013 支持约 5µs~10s;滑条范围可在 ui 内放宽 |
| 增益 | 0 dB | 0~16dB;增益越高噪点越多,可能抬高 N 基线 |
| 目标帧率 | 30 fps | 相机源按其自身能力;模拟/图片源按此限速 |

建议固定曝光后再抓缺陷阈值(高亮统计对光照敏感)。

## config.json 关键项

```jsonc
{
  "source": "sim",            // sim / image / hik
  "roi_x/y/w/h": [0,0,1280,1024],
  "window_r/g/b": {"lo":180,"hi":255},
  "alarm_count": 800,          // 报警阈值:N≥此值
  "debounce_frames": 3,        // 连续帧数
  "show_mask": true,           // 命中像素红色蒙层
  "use_serial": true, "serial_port": "COM2", "serial_baud": 9600,
  "exposure_us": 2000, "gain_db": 0.0, "target_fps": 30
}
```
